# Image Studio

Crop, resize, compress and convert. A small studio for everyday image work.

A working utility that processes data locally in the browser. No accounts, API keys, or server file storage.

## Run

Node.js 22 or newer.

```sh
npm install
npm run build
npm run dev
```

## Features

- Drag a crop selection or choose an aspect ratio
- Resize, rotate, compress and convert JPG, PNG and WebP
- Download processed images; files remain in the browser

## Embed

Use `?embed=1&theme=light` (or `dark`) for the compact homepage demo. Theme follows the operating system by default, with an optional saved preference.

## Deployment

Vercel serves the generated `dist` directory.
